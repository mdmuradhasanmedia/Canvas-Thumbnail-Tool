# Canvas Thumbnail Tool

Advanced HTML5 Canvas Thumbnail Generator for GitHub Pages.

## Live Demo

https://mdmuradhasanmedia.github.io/Canvas-Thumbnail-Tool/

---

# Features

- Live Preview
- Dynamic Title
- Dynamic Subtitle
- Subtitle ON/OFF
- Credit Text ON/OFF
- Multiple Themes
- Background Image Upload
- Auto Font Resize
- URL Parameter Support
- PNG Download
- Mobile Friendly
- No Backend Required
- GitHub Pages Ready

---

# URL Parameters

You can generate thumbnails directly using URL parameters.

## Example

```txt
https://mdmuradhasanmedia.github.io/Canvas-Thumbnail-Tool/?title=Hello&subtitle=New%20Video&theme=red&credit=BanglaTrick&showcredit=true&showsubtitle=true
```

---

# Supported Parameters

| Parameter | Example | Description |
|---|---|---|
| title | Hello World | Main title |
| subtitle | New Video | Subtitle text |
| theme | red | Theme color |
| credit | BanglaTrick | Credit text |
| showcredit | true | Show or hide credit |
| showsubtitle | true | Show or hide subtitle |

# Installation

## 1. Clone Repository

```bash
git clone https://github.com/mdmuradhasanmedia/Canvas-Thumbnail-Tool.git
```

---

## 2. Open Project

```txt
index.html
```

---

## 3. GitHub Pages Setup

Go to:

```txt
Settings → Pages
```

Select:

```txt
Deploy from branch
```

Choose:

```txt
main branch
/root
```

Save.
